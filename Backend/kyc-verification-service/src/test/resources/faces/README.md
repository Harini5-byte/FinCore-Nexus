# Test fixtures (not bundled)

This project does not ship real photographs of people as test fixtures.

To run `OpenCvFaceMatchServiceTest#realFaceMatchAgainstSampleImages`
end-to-end, place two photos of the *same* person here:

- `person-a-1.jpg`
- `person-a-2.jpg`

The test is skipped automatically (not failed) if these are absent.
